\# AUROUAV Mapping Module



Provides multi‑layer mapping:



\- Local occupancy grid

\- Global voxel map

\- Semantic fusion (Bayesian updates)



\### Nodes

\- local\_map\_node

\- global\_map\_node

\- semantic\_fusion\_node



\### Outputs

\- /auro\_uav/local\_map

\- /auro\_uav/global\_map

\- /auro\_uav/semantic\_map
