🚀 Introducing AUROUAV — A Unified Autonomy Architecture for GNSS‑Denied UAV Navigation

Thrilled to share my latest project: AUROUAV, a modular autonomy stack designed for UAVs operating in GNSS‑denied environments such as forests, tunnels, collapsed structures, and indoor spaces.

AUROUAV integrates:

🔹 Transformer‑based perception (ViT‑DETR, semantic segmentation)
🔹 Reactive control (DroNet steering + collision)
🔹 Visual‑inertial SLAM (factor‑graph)
🔹 Semantic voxel mapping
🔹 MPC trajectory optimization
🔹 RL‑conditioned steering priors
🔹 PX4 offboard control
🔹 AirSim → PX4 SITL → Gazebo simulation pipeline

Optimized for Jetson Orin / Xavier / Nano, AUROUAV brings together deep learning, SLAM, mapping, planning, and safety into a single deployable system.
