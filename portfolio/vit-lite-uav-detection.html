Lightweight Vision Transformer (ViT‑Lite)

Optimized Transformer‑Based UAV Detection for GNSS‑Denied Environments

Overview

ViT‑Lite is a compact Vision Transformer architecture optimized for UAV object detection under GNSS‑denied conditions. It achieves high accuracy with low computational cost, enabling deployment on edge UAV hardware.

Architecture

  • Patch embedding
  • Lightweight multi‑head attention
  • Reduced‑depth transformer blocks
  • Edge‑optimized inference

Key Contributions

  • Compact ViT architecture for UAVs.
  • High accuracy with low compute.
  • Robust detection in degraded environments.
