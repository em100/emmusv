Temporal Emotion Trajectory Modeling

Hybrid NLP Framework for Modeling Emotional Progression in Text

Overview

This project introduces a hybrid NLP framework for modeling emotional progression across clinical and informal text. It integrates transformer‑based embeddings with temporal sequence modeling.

Architecture

  • Transformer embeddings
  • Temporal sequence modeling
  • Emotion trajectory extraction
  • Clinical + informal text fusion
