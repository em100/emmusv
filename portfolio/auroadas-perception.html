AUROADAS Perception System

A Modular Multi‑Sensor Fusion & Perception System for Long‑Sighted ADAS → ADS Autonomy

Overview

AUROADAS is a modular perception system designed for long‑sighted ADAS → ADS autonomy. It integrates multi‑sensor fusion, deep learning object detection, and robust localization to deliver reliable perception in complex urban and highway environments.

System Architecture

  • Camera + LiDAR + Radar fusion pipeline
  • Transformer‑based object detection
  • Real‑time tracking & motion prediction
  • Long‑range situational awareness
  • ADAS → ADS modular upgrade path

Technical Stack

Deep Learning (CNN / ViT)
Sensor Fusion
Optical Flow
ADAS Safety Constraints
Real‑Time Edge Deployment

Key Contributions

  • Long‑range perception for ADAS → ADS autonomy.
  • Modular multi‑sensor fusion architecture.
  • Transformer‑based object detection optimized for edge hardware.
  • Robust tracking and motion prediction in dynamic environments.
