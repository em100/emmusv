AUROUAV Autonomy Architecture

A Multi‑Sensor Autonomy Stack for Aerial Robots

Overview

AUROUAV is a unified autonomy architecture integrating perception, mapping, obstacle avoidance, and mission planning for UAVs operating in dynamic and GPS‑denied environments.

System Architecture

  • Stereo vision + IMU + VIO fusion
  • SLAM‑based mapping and localization
  • Deep learning object detection
  • Adaptive obstacle avoidance
  • Mission‑level planning and control

Technical Stack

SLAM
VIO
Deep Learning
Trajectory Planning
UAV Control

Key Contributions

  • Unified autonomy pipeline for aerial robots.
  • Robust mapping in GPS‑denied environments.
  • Adaptive obstacle avoidance using learned priors.
  • Mission‑level planning integrated with perception.
