AUROUAV: Multi‑Sensor Autonomy Architecture for Aerial Robots

Deep learning image-based object detection for autonomous UAV navigation.

Overview

This project develops a vision-based “see and avoid” system for UAVs operating in GPS-denied environments, combining deep learning object detection with optical flow and robust navigation strategies.

Technical Stack

  • Deep learning object detection (CNN/Transformer-based)
  • Optical flow and motion estimation
  • UAV control integration and safety constraints

Key Contributions

  • Reliable obstacle detection without GNSS.
  • Real-time performance on edge hardware.
  • Improved safety in constrained environments.

Publication
