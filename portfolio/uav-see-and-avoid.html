UAV “See and Avoid” Navigation

Vision‑Based Obstacle Detection for GPS‑Denied UAV Flight

Overview

This project develops a vision‑based obstacle detection system enabling UAVs to navigate safely without GNSS. The pipeline integrates deep learning object detection, optical flow, and motion‑aware navigation strategies.

Pipeline Architecture

  • Real‑time object detection
  • Optical flow motion estimation
  • Depth inference from monocular cues
  • Collision prediction
  • Reactive avoidance control

Technical Stack

CNN / ViT
Optical Flow
Motion Prediction
UAV Control

Key Contributions

  • Reliable obstacle detection without GNSS.
  • Real‑time performance on embedded hardware.
  • Improved safety in constrained environments.
