Introducing AUROUAV — A Unified Autonomy Architecture for GNSS‑Denied UAV Navigation

Bay City, MI — AUROUAV, a next‑generation autonomy stack designed for UAVs operating in GNSS‑denied environments, is now available as an open‑source project. Developed by AI/ML Engineer Emmanuel Musvaire, AUROUAV integrates transformer‑based perception, visual‑inertial SLAM, semantic voxel mapping, model predictive control (MPC), and reinforcement‑learning‑conditioned steering priors into a single, modular system optimized for NVIDIA Jetson platforms and PX4‑based UAVs.

AUROUAV enables UAVs to navigate reliably in forests, tunnels, collapsed structures, and indoor spaces where GNSS signals are unavailable or unreliable. The system leverages GPU‑accelerated inference, simulation‑driven development, and safety‑aware control to deliver robust autonomy in challenging real‑world environments.

The project includes a complete perception stack (DroNet, depth estimation, semantic segmentation, ViT‑DETR), multi‑layer mapping, hierarchical planning, PX4 offboard control, and a full AirSim → PX4 SITL → Gazebo simulation pipeline.
